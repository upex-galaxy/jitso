## Goal

Find where the sync entry point of this project is defined and explain in a few sentences how it is wired to the rest of the code.

## Scope

Read only. Do not change any file and do not leave the repository.

## Done when

You can name the file and the line that defines the entry point, and you have checked it by reading the file.

## Report format

One short paragraph with the file path, the line number and a one line summary of what it does.
